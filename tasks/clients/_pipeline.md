## Pipeline

| Client               | Trade       | Stage | Site Folder                  | Domain                         | Assets        | Brief                            |
| -------------------- | ----------- | ----- | ---------------------------- | ------------------------------ | ------------- | -------------------------------- |

---

## Stage Definitions

| Stage         | Description                                         |
| ------------- | --------------------------------------------------- |
| **PROSPECT**  | Identified as potential client, not yet contacted   |
| **CONTACTED** | Initial outreach made, awaiting response            |
| **BRIEF**     | Client engaged, collecting business info and assets |
| **BUILD**     | Site being created (generated + customised)         |
| **REVIEW**    | Client reviewing site, providing feedback           |
| **LIVE**      | Deployed with custom domain, handed off to client   |

## Intake Checklist

Standard information needed for every new client:

### Business Details

- [ ] Business name (trading name + legal name)
- [ ] Trade / industry
- [ ] Phone number
- [ ] Email address
- [ ] Physical address
- [ ] Business hours
- [ ] Year established
- [ ] Social media links

### Brand Assets (store in Google Drive)

- [ ] Logo (SVG preferred, PNG minimum)
- [ ] Brand colours (primary, secondary) or existing website URL to extract from
- [ ] Photos (team, premises, work examples)
- [ ] Certifications / accreditations

### Site Content

- [ ] Key services to feature (3-10)
- [ ] Service areas / locations to cover
- [ ] Existing testimonials or reviews
- [ ] Any existing content to migrate

### Domain & Email (we manage)

- [ ] Preferred domain name
- [ ] Existing domain to transfer? (or we purchase new)
- [ ] Email address(es) needed (e.g. info@, name@)
- [ ] Google My Business listing URL
- [ ] Package tier (Starter / Professional / Growth) — see [pricing](../gtm/strategy.md#proposed-tiers)
