  - question: "Can you print from A4 to A0 in one run?"
    answer: "Yes. Our wide-format digital printer handles A4 through to A0 (and beyond, up to 1500mm wide) on the same machine — so we can produce multiple sizes from the same file in a single run. This is efficient when you need the same poster in different sizes for different display locations."
  - question: "What resolution do posters need to be?"
    answer: "For A3 and below, 300dpi at print size is recommended. For A2 and A1, 150dpi at print size is sufficient. For A0 and large format, 100dpi is adequate for typical viewing distances. We check your file before printing and will flag if resolution is an issue at the intended output size."
  - question: "Do you laminate posters?"
    answer: "Yes. Lamination in gloss, matt, or anti-glare finish protects posters from handling, moisture, and UV fade. Lamination is recommended for posters that will be displayed for more than a few weeks, used repeatedly, or mounted in frames without glass protection."
