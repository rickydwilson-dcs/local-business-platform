## Intruder Alarm System Components

**Control Panel**

The heart of your alarm system:

- Professional panel with battery backup
- Programmable entry/exit delays
- Support for multiple users and access codes
- Local siren and external alarm outputs
- Integration with monitoring centre
- Tamper protection and backup alerts

**Motion Sensors (PIR)**

Detect movement within protected areas:

- Passive infrared technology
- Pet-immune options available (for homes with animals)
- Multiple detection zones
- Adjustable sensitivity settings
- Quiet operation (no false alarms from pets)

**Door & Window Contacts**

Detect opening of entry points:

- Wireless or wired options
- Discreet installation (small, hidden sensors)
- Protection for all external doors and windows
- Glass break detection available

**Alarm Sirens**

Alert you and deter intruders:

- Loud audible alarm (85-100 dB)
- Internal siren (notification within property)
- External siren (visual strobing light + sound)
- Flashing LED beacon for visual deterrent

**Monitoring & Notifications**

Stay informed 24/7:

- Smartphone app with real-time alerts
- SMS text notifications
- Email alerts
- 24/7 monitoring centre dispatch (optional)
- Direct police dispatch on confirmed alarm

## System Types

**Wireless Alarm Systems**

Modern wireless systems offer:

- Easier installation (no cable running)
- Flexible sensor placement
- Battery-powered sensors (7-10 year lifespan)
- Lower installation disruption
- Portable if moving home
- Slightly higher ongoing costs for batteries and monitoring

**Hardwired Alarm Systems**

Traditional hardwired systems offer:

- No battery maintenance needed
- Lower long-term operating costs
- Reliable (no wireless interference)
- Professional-looking installation
- Requires more cable installation during setup

## Alarm Installation Process

1. **Security Survey** - Assess your property for vulnerabilities and sensor placement
2. **System Design** - Recommend alarm type, sensors, and monitoring level
3. **Panel Installation** - Install control panel in secure, accessible location
4. **Sensor Installation** - Place motion sensors, door/window contacts at entry points
5. **Wiring Installation** - Run cables (if hardwired) or configure wireless network
6. **Siren Installation** - Install internal and external sirens
7. **System Configuration** - Program entry/exit delays, user codes, monitoring
8. **Testing & Commissioning** - Full system test to ensure all zones function
9. **User Training** - Explain operation, codes, emergency procedures
10. **Monitoring Setup** - Configure 24/7 monitoring centre integration if required
