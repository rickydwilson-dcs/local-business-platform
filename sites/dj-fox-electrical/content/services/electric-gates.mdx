## Gate System Types

**Sliding Gate Systems**

Popular for modern installations:

- **Operation:** Gate slides horizontally across driveway
- **Space:** Requires space equal to gate width (no swing space needed)
- **Ideal for:** Limited space, modern aesthetic, high security
- **Motor Type:** Linear actuator (belt or chain drive)
- **Installation:** 1-2 days typical
- **Cost:** £2,500-6,000 typical (gates + installation)

**Swing Gate Systems**

Traditional option for established properties:

- **Operation:** Gate(s) swing inward or outward on hinges
- **Space:** Requires clear swing area (minimal if pillar-mounted)
- **Ideal for:** Residential driveways, established properties
- **Motor Type:** Swing arm actuators (2 motors for double gates)
- **Installation:** 1 day typical
- **Cost:** £2,000-5,000 typical

**Comparison:**

| Factor | Sliding | Swing |
|--------|---------|-------|
| Space Required | Equal to gate width | Gate width swing area |
| Maintenance | Requires track cleaning | Lower maintenance |
| Cost | Slightly higher | Slightly lower |
| Aesthetic | Modern | Traditional |
| Reliability | Very reliable | Very reliable |

## Control Systems

**Remote Control Access**

Wireless operation:

- Handheld remote fob (range: 50-100+ metres)
- Vehicles can open gate automatically
- Multiple users with separate codes
- Battery-powered (typical life: 2-3 years)
- Backup manual operation if batteries fail

**Keypad Entry**

PIN code entry:

- Visitor or delivery access without remote
- Time-limited codes possible
- Audit trail of entries
- Suitable for commercial properties
- Integration with intercom systems

**Photocells (Safety Beams)**

Automatic obstacle detection:

- Infrared beam across gate path
- Automatically stops/reverses gate if beam broken
- Essential safety feature (required for compliance)
- Protects against accidental injury
- Installed on both sides of gate

**Intercom Integration**

Two-way communication:

- Visitor announcement capability
- Remote gate opening from inside property
- Video intercom options (see visitor on camera)
- Voice communication feature
- Integration with CCTV systems

**Access Control Integration**

Professional systems:

- Integration with keycard or fob access control
- Automated access logs (who opened gate, when)
- Integration with alarm systems
- Unified security system management
- Commercial properties benefit most

## Sliding Gate Installation

**Components:**

1. **Motor & Control Panel** - Linear motor with control electronics
2. **Track System** - Heavy-duty aluminum or steel track
3. **Rollers & Guides** - Support gate on track, reduce friction
4. **Safety Photocells** - Prevent gate operation if beam blocked
5. **Remote Control & Batteries** - Wireless operation capability
6. **Emergency Manual Release** - Manual operation if power lost
7. **Post/Pillar Mounted** - Usually on entrance pillar(s)

**Installation Process:**

1. Site assessment and track route planning
2. Prepare posts/pillars for mounting
3. Install track system (horizontal)
4. Mount motor and control panel
5. Hang gate on track and rollers
6. Adjust gate alignment and operation
7. Install photocells and test operation
8. Configure remote controls and access systems
9. Install emergency override mechanism
10. Full safety testing and certification

**Typical Timeframe:** 1-2 days for standard installation

## Swing Gate Installation

**Components:**

1. **Swing Arm Motors** - Typically 2 for double gates (1 for single)
2. **Control Panel** - Manages motor operation
3. **Hinges & Pillars** - Support gate weight (heavy-duty required)
4. **Safety Photocells** - Stop gate if obstacle detected
5. **Leaf Guides** - Ensure proper alignment
6. **Remote Control** - Wireless opening capability
7. **Emergency Manual Release** - Manual operation backup

**Installation Process:**

1. Assess existing gate structure
2. Upgrade hinges and pillars if necessary
3. Install swing arm motors
4. Install control panel and power supply
5. Mount safety photocells
6. Configure and test operation
7. Pair remote controls
8. Set opening/closing speeds and delays
9. Install emergency override
10. Safety testing and certification

**Typical Timeframe:** 1 day for standard installation

## Electrical Requirements

Each electric gate installation requires:

**Power Supply:**

- 230V single-phase supply to control panel
- 10A circuit recommended (smaller may be acceptable)
- Dedicated circuit breaker protection
- RCD protection for safety
- Location: typically in entrance pillar or nearby

**Battery Backup:**

- Ensures gate operation if power fails (typically 12V DC)
- Allows several open/close cycles without mains power
- Standard feature on most systems
- Battery replacement needed every 3-5 years

**Emergency Manual Operation:**

- Manual release mechanism to open gate without power
- Allows property exit if electrical failure
- Important safety feature
- Typically located on control panel

**Installation Cost:**

- Electrical circuit: £300-500
- Power supply to pillar: £200-400
- Total electrical: £500-900

## Safety Features & Compliance

**Photocell Safety Beams**

Most important safety feature:

- Automatically stops gate if beam blocked
- Prevents injury to people caught in gate path
- Infrared beam across opening
- Installed on both sides
- BS EN 12453 compliant

**Emergency Manual Override**

Required by regulations:

- Manual release lever or key
- Allows gate opening without power
- Located on control panel
- Clearly labelled for emergency use
- Critical for fire safety compliance

**Auto-Close Function**

Time-based security:

- Gates automatically close after set time (typically 10-30 seconds)
- Prevents unauthorized access
- Audible warning before closing
- Essential security feature

**Audible/Visual Warning**

Legal requirement:

- Audible alarm before gate operation
- Visual light/beacon flashing
- Warns of impending gate movement
- Prevents accidental injury

**UPS (Uninterruptible Power Supply)**

Optional backup power:

- Ensures gate operation during power cuts
- Typically 12V battery backup
- Allows multiple cycles per charge
- Peace of mind for emergencies
