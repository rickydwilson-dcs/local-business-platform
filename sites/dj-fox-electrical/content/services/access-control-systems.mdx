## Access Control System Types

**Keypad Entry Systems**

Simple PIN-code based entry:

- Up to 99+ unique user codes
- Easy to change codes quickly
- No cards or fobs to carry
- Codes can be time-limited
- Suitable for smaller properties
- Low initial cost
- Can be standalone or networked

**Proximity Card & Fob Systems**

Radio frequency based entry:

- Individual cards or fobs assigned to users
- Instant read (no need to type codes)
- Cards easily deactivated if lost
- Audit trail of all entries
- Professional appearance
- Flexible access levels per user
- Integration with time & attendance

**Biometric Systems**

Fingerprint or facial recognition:

- Highly secure (cannot be borrowed or stolen)
- No cards or codes to manage
- Fast entry (no typing required)
- Unsuitable for gloved workers
- Higher cost but premium security
- Often combined with PIN backup

**Intercom Integration**

Two-way communication systems:

- Visitor announcement and identification
- Remote entry authorization
- Video intercom options available
- Integration with access control panel
- Multiple call stations supported
- Remote door unlock from office

## System Components

**Access Control Panel**

The central processing unit:

- Manages all access points and users
- Processing of card/fob/keypad inputs
- Door lock relay outputs
- Integration with alarms and CCTV
- Battery backup for emergency situations
- Network connectivity (TCP/IP)
- Multiple controller network capability

**Electronic Door Locks**

Secure door fastening devices:

- Magnetic locks (fail-safe, release on power loss)
- Electric door strikes (fail-secure, locked on power loss)
- Motorized push-button locks
- Suitable for glass and metal doors
- Fully integrated with access control
- Adjustable hold times

**Card/Fob Readers**

Detection and identification devices:

- Proximity technology (13.56 MHz standard)
- Long read distance (up to 1 meter+)
- Vandal-resistant stainless steel models
- Multiple card formats supported
- Weather-resistant outdoor options
- Integrated LED status indicators

**Keypads**

PIN entry devices:

- Illuminated buttons for 24/7 use
- Backlit display
- Programmable access logic
- Acoustic feedback options
- Weather-resistant designs
- Multiple format support

**Emergency Exit Controls**

Safety integration:

- Pushbutton emergency exit doors
- Fail-safe exit (door opens on power loss)
- Prevent unauthorized reverse entry
- Alarm outputs on emergency use
- Meets Building Safety Regulations
