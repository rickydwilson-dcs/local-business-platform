## What a platform website includes

Every site on the DCS platform ships with the same foundation: a Next.js application, edge-cached on Vercel, with structured data, Core Web Vitals monitoring, and automated security updates built in.

We don't sell themes. We configure a design system specific to your brand and generate a site that looks custom because it is — it just runs on infrastructure we maintain for every client.

### What's built in by default

- **Core Web Vitals optimisation** — LCP, CLS, and INP targets met at launch, not retrofitted
- **Schema.org structured data** — LocalBusiness, Service, BreadcrumbList, and FAQ schema generated from content
- **Technical SEO** — meta tags, canonical URLs, sitemap, robots.txt
- **Image CDN** — all images served via R2 with automatic WebP conversion and lazy loading
- **Contact form** with rate limiting, CSRF protection, and Resend email delivery
- **Analytics ready** — GA4 and Google Search Console configured if required

### Content management

Content lives in MDX files. Add a file to `content/services/` and a new service page appears at `/services/slug` automatically — no routing changes, no code deploys. The same applies to blog posts, location pages, and case studies.

### Ongoing platform updates

We run update sprints every two weeks. Security patches, dependency upgrades, and platform-level feature improvements roll out to all sites without client involvement. You get improvements automatically because your site runs on shared infrastructure, not an isolated codebase.
