## SEO that starts with the foundation

Most SEO problems are technical problems. Before content or links, a site needs to be crawlable, indexable, fast, and correctly marked up. We fix those things first because they're the highest-leverage work.

### Technical SEO

We audit every site against a 40-point technical checklist covering crawl budget, indexation, redirect structure, canonical URLs, page speed, and mobile usability. Issues are triaged by impact: critical, high, medium, and low. You get a report with clear explanations of why each issue matters and exactly how to fix it.

### Structured data

We implement schema.org markup for every relevant entity on the site:

- **LocalBusiness** — name, address, phone, opening hours, geo coordinates
- **Service** — service name, description, area served
- **FAQPage** — extracted from MDX frontmatter, validated against Google's requirements
- **BreadcrumbList** — hierarchical page structure for SERP display

All markup is tested with Google's Rich Results Test and Search Console before launch.

### Analytics

GA4 out of the box is a confusing mess. We configure it properly: events for meaningful actions, custom dimensions for site-specific data, a clean dashboard that shows the five numbers you actually need to make decisions, and a monthly automated report delivered to your inbox.

We also connect Search Console so you can see which queries bring visitors to which pages, and track position changes over time.
