# Inbox — client-supplied material

Drop what David sends here: logo files, photography, video cuts, copy documents, press PDFs.

**Nothing binary in this folder reaches git.** `output/.gitignore` denies images and video across
`sessions/**` by design — assets belong in R2, not the repo. That includes a vector logo: keep it
here to work from, and it ships via R2 or the site's own `public/` when the build starts.
