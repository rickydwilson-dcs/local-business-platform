# Sources — etype-941pvo assets

All images in this folder are downloaded originals from **etypefhcseries1.com**, Mark Antwis's own
site for the E-type 941 PVO (a Lovable-built SPA; images live under `/assets/<hash>.jpg` on that
domain, not discoverable from raw HTML — extracted via a headless-browser DOM query, not scraping).
Recompressed with `sips -s formatOptions 78` to bring file size down without changing dimensions;
no cropping, no other edits.

Owner confirmed (via David, 2026-09-05) these images are free to use. **The written page built
around them is not yet cleared** — see `etype-941pvo.html`'s own footer note.

that to someone else's photograph without risking a visibly botched edit, so these three frames
were excluded rather than used and redacted. Full gallery has ~57 images; 12 curated here, matching
the Volvo P1800 record's practice of using a curated set rather than all of DPM's own library.
