Paste into Claude Code:
I need you to commit and deploy my current changes through our full git workflow. Follow these steps as a single atomic operation — if any step fails, stop and report: 1. Verify we're on the `develop` branch. If not, stash changes, switch to develop, and apply. 2. Run `pnpm install` and `pnpm build` to confirm clean build. Fix any lockfile sync issues. 3. Commit with a conventional commit message summarizing all changes. 4. Push to develop and wait for CI to pass (check GitHub Actions status). 5. Merge develop → staging, push staging, wait for CI. 6. If CI fails at any stage, diagnose and fix the issue, then retry that stage before proceeding.
