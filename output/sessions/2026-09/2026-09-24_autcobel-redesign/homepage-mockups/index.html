Autcobel — 10 homepage concept explorations

Internal review only. Each version invoked a different design skill against the same content and the same brief: lighter blue as the dominant hero colour, and some visual expression of data-centricity + solutions delivery (not necessarily the real site's globe graphic).

  • ui-ux-pro-max
    v1 — Bold neubrutalist

    Lighter cobalt-to-sky gradient hero, animated circuit-schematic hub, asymmetric bento pillars, marquee sectors.

  • minimalist-ui
    v2 — Minimalist editorial

    Warm off-white body, editorial serif headings, quiet HUD-style data panel in the hero instead of a busy graphic.

  • industrial-brutalist-ui
    v3 — Industrial brutalist

    Swiss print substrate, zero radii, blueprint circuit schematic with animated dashed traces and a telemetry ticker.

  • high-end-visual-design
    v4 — High-end agency

    Glass-pill nav, Fraunces/Space Grotesk type, live "delivery signal" waveform panel, bento pillars.

  • stitch-design-taste
    v5 — Kinetic signal field

    Asymmetric split hero, pulsing/drifting animated node field on the right, auto-scrolling sectors marquee.

  • design-taste-frontend
    v6 — Engineered PCB console

    Outfit/JetBrains Mono pairing, bordered "network console" PCB-trace panel, indexed rows instead of cards.

  • redesign-existing-projects
    v7 — Evolve the real brand

    Keeps the real site's cobalt/globe DNA, lightens it, upgrades the globe to a layered animated sphere.

  • impeccable
    v8 — Bold live network

    Vivid lighter-cobalt hero with animated light-pulse circuit traces and a floating live-status glass card.

  • design
    v9 — Brand-identity led

    Bespoke circuit-trace "A" monogram, hand-built orthogonal icon set, monospace data-readout type layer.

  • ui-styling
    v10 — SaaS dashboard console

    shadcn/Tailwind-flavoured product page, floating "Delivery Console" dashboard with live sparkline.
